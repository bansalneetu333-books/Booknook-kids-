# Deployment

This release is designed for the existing Booknook Kids Vercel + Supabase project.

1. Replace the GitHub repository files with this release.
2. Commit to `main`.
3. Let Vercel deploy using the environment variables already present in the project.
4. No new Vercel variable is required by this release.
5. No Supabase migration is required by this release.

Do not commit secrets or `.env` files.
